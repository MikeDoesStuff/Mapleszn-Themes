# Mapleszn

Maple-season themes: warm leaf accents on cool grey bases that never turn brown. Nine themes, each in dark and light.

| Theme | Accent |
|---|---|
| Maple Frost | Red maple on frosted blue-slate |
| Maple Momiji | Japanese-maple vermilion on ink grey |
| Maple Dusk | Apricot on smoky plum |
| Maple Sugar | Sugar-maple gold on cool slate |
| Maple Ember | Amber and copper on charcoal-slate |
| Maple Cinder | Terracotta on graphite |
| Maple Oat | Pale honey on greige |
| Maple Mist | Icy blue on blue-grey |
| Maple Twilight | Lavender on blue-plum |

## t3code

Install from Open VSX in t3code's theme settings, or import the `.vsix`. Each Dark/Light pair imports as one theme that follows your appearance setting.

## VS Code

Open the Command Palette, run **Preferences: Color Theme** and choose any Maple theme.

Preview every theme at [mikedoesstuff.github.io/Mapleszn-Themes](https://mikedoesstuff.github.io/Mapleszn-Themes/).
