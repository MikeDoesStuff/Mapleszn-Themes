How the new ones were built

  • Neutrals and accent are separate dials. Each theme is a tinted neutral ramp (one hue, very low chroma, stepped in OKLCH lightness) plus one leaf-coloured accent, the same split Material's theme builder uses between its neutral and primary palettes.
  • Complementary pairs. Frost and Sugar put a warm leaf accent on a cool blue-slate base. Blue and orange sit opposite each other, so the accent reads as maple without the background going brown.
  • Mist and Twilight kept, re-leafed. Frost is Mist's base with a red maple accent; Dusk is Twilight's base with apricot instead of lavender.
  • Harmonised status colours. Error, warning and update hues are nudged up to 15° toward the accent, like Material's harmonize(), so they belong to the palette.
  • Comments set the ceiling. The fixed comment grey is the weakest syntax colour, so code backgrounds stay around OKLCH L 0.30–0.32. Going lighter would wash comments out.
